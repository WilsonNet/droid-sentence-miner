Droid Sentence Miner is a free, open-source Android app for learning Japanese through
immersion. It captures text that is already on your screen — a game's dialogue box, a YouTube
hardsub, a manga page — and turns it into a dictionary lookup and a complete Anki card.

It is inspired by [GameSentenceMiner](https://github.com/bpwhelan/GameSentenceMiner) and built
around [Yomitan](https://github.com/yomidevs/yomitan) dictionaries.

## What you need

<CardGrid>
  <Card title="Android 8.0+" icon="phone">
    Audio capture needs Android 10 or newer. Screen sharing uses the standard Android 14/15 app
    picker when it is available.
  </Card>
  <Card title="Anki" icon="pencil">
    [AnkiDroid](https://github.com/ankidroid/Anki-Android) on the same phone, or desktop Anki
    with the AnkiConnect add-on on your network.
  </Card>
  <Card title="Dictionaries" icon="open-book">
    Install Jitendex, JMdict or Kanjium pitch accents with one tap, or import any Yomitan format 3
    zip.
  </Card>
  <Card title="No root" icon="laptop">
    Everything uses normal Android screen-sharing consent. No root, no emulator, no desktop
    companion.
  </Card>
</CardGrid>

## How it fits together

```
MediaProjection → screen capture → OCR (meikiocr / ML Kit) → line tracker
                                                               ↓
Yomitan dictionary database ← deinflection ← lookup ← text log + screenshot + voice clip
                                                               ↓
                                              AnkiDroid API or AnkiConnect
```

Every part runs on the phone. Dictionaries and the Japanese OCR model are downloaded once; after
that, reading, lookup and card building work offline. See [How it works](reference/how-it-works/)
for the details.
